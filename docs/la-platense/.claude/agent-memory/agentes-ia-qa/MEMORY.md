(fuente de verdad compartida); aca van solo aprendizajes reutilizables de ESTE proyecto.

- [Control positivo en el commit anterior](feedback_control_positivo_commit_anterior.md) — los numeros declarados de un arnes no se creen: se reproducen contra el commit previo, que es lo unico que separa lo que el fix rompio de lo que ya estaba roto.
- [Las cuatro formas de falso verde de La Platense](project_falsos_verdes_la_platense.md) — el catalogo vivo de como los arneses de este proyecto mienten, y la cuarta (el arnes muere o no mide) con su barrido.
- [El criterio de re-verificacion se reescribe](feedback_criterio_reverificacion_se_reescribe.md) — cuando el fix cambia el diseno en vez de poner la guarda, el criterio del parte queda inverificable: se reescribe sobre el invariante y se declara.
